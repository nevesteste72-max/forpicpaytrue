O que é o SA Ecom Start 2.0

É um modelo de revenda sem comprar stock primeiro. Você anuncia o produto de um fornecedor, o cliente paga a você antes, e só depois você compra e despacha. O lucro é a diferença entre o que o cliente pagou e o preço de atacado.

  1. Você publica o anúncio (Marketplace/WhatsApp) usando fotos e preços do fornecedor.
  2. O cliente paga antes — por EFT, Capitec Pay, Ozow ou cartão.
  3. Só depois de receber, você compra do fornecedor pelo preço de atacado.
  4. Você despacha direto para o cliente via Paxi ou Courier Guy.
⚠️ Risco zero de stock parado — mas isso também significa que nunca despache antes de confirmar o pagamento (ver Módulo 3, checklist anti-golpe).

Como criar sua loja no Shopify

🛍️Passo a passo

  1. Crie a conta em shopify.com e escolha o plano básico.
  2. Em "Temas", instale um tema gratuito (ex.: Dawn) e ajuste cores/logo para combinar com sua marca.
  3. Em "Produtos", cadastre cada item com fotos do fornecedor, preço em ZAR e descrição (reaproveite os textos do Módulo 2).
  4. Em "Definições → Transporte", crie zonas de entrega e associe às tabelas da Paxi e Courier Guy (Módulo 3).
  5. Ligue um domínio próprio (ex.: .co.za) em "Domínios" — opcional, mas passa mais confiança.
💡 A Shopify Payments nativa não cobre todos os bancos sul-africanos. Por isso o passo seguinte ensina a ligar Stripe/Ozow/PayFast como gateway.
Integrar Stripe na sua loja Shopify
  1. Crie uma conta em stripe.com e complete a verificação de negócio (dados da empresa/CPF-CNPJ ou equivalente sul-africano).
  2. Na Shopify, vá em "Definições → Pagamentos → Adicionar novo gateway" e procure por "Stripe" na lista de parceiros, ou instale a app "Stripe Payments" na Shopify App Store.
  3. Copie a sua Publishable key e Secret key do painel Stripe (Programadores → Chaves de API) e cole nos campos da app.
  4. Ative o gateway e faça uma compra de teste em modo sandbox antes de abrir ao público.
Integrar Stripe no seu próprio site (projeto raiz)

Se você (ou alguém que contratou) está a construir um site próprio em vez de usar a Shopify, o fluxo mínimo com Stripe Checkout é este:

  1. Instale o SDK: npm install stripe
  2. No servidor, crie uma sessão de checkout apontando para o seu produto e URLs de sucesso/cancelamento.
  3. Redirecione o cliente para o session.url devolvido pela Stripe.
  4. Configure um webhook (checkout.session.completed) para liberar o acesso ou disparar o envio assim que o pagamento for confirmado.
// server.js — criar sessão de checkout const stripe = require('stripe')(process.env.STRIPE_SECRET_KEY); const session = await stripe.checkout.sessions.create({ mode: 'payment', line_items: [{ price_data: { currency: 'zar', product_data: { name: 'SA Ecom Start 2.0' }, unit_amount: 19700, // R197.00 em centavos }, quantity: 1, }], success_url: 'https://seusite.co.za/obrigado?session_id={CHECKOUT_SESSION_ID}', cancel_url: 'https://seusite.co.za/checkout', }); res.redirect(303, session.url);
🔑 Nunca coloque a Secret key no código do navegador — ela fica só no servidor. No front-end use apenas a Publishable key.

✍️Prompt pronto — copie e cole na IA

Crie uma landing page de vendas moderna e mobile-first para a minha loja de revenda online na África do Sul chamada "[NOME DA SUA LOJA]". Especificações: - Tema visual escuro com um verde/teal de destaque (transmitir confiança e tecnologia) - Seção principal (hero) mostrando o produto "[SEU PRODUTO PRINCIPAL]" com preço em Rand (R) - Galeria de produtos: foto, nome, preço e botão "Comprar" - 3 depoimentos de clientes fictícios de exemplo (vou substituir por reais depois) - Selo de confiança citando: aceita Capitec, FNB, Standard Bank, Nedbank e EFT instantâneo via Ozow - Botão de checkout ligado a "[SEU LINK DE PAGAMENTO STRIPE/OZOW/PAYFAST]" - Rodapé com política de entrega via Paxi e The Courier Guy - 100% responsivo (celular, tablet, desktop), rápido, sem exigir login - Código simples em HTML/CSS/JS ou React, sem frameworks pesados desnecessários Depois de gerar a primeira versão, vou pedir para você: 1. "Ligar o botão de compra ao Stripe Checkout" 2. "Adicionar uma página de agradecimento com o número de rastreio" 3. "Deixar o menu mobile mais fácil de usar com o polegar"

💡Como falar com a IA (para não perder tempo)

  • Peça uma mudança de cada vez — "muda só a cor do botão para verde" funciona melhor do que pedir 5 coisas juntas.
  • Mostre o que está errado com detalhe: "o texto do preço está cortado no celular" em vez de "está feio".
  • Peça sempre para testar em tela de celular antes de aprovar — a maioria dos seus clientes vai comprar pelo telemóvel.
  • Guarde o link do projeto assim que gostar de uma versão — muitas dessas ferramentas permitem voltar a versões anteriores.

🚀Onde publicar

Lovable, v0 e bolt.new já publicam automaticamente com um link. Se gerou código à parte (Claude/ChatGPT), suba num destes serviços gratuitos: Vercel ou Netlify — arraste a pasta do projeto e em minutos tem um link público. Depois ligue seu domínio próprio (.co.za) nas definições do projeto.
